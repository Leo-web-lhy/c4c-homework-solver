# 2023108610260_C4C 教学说明

面向教师与助教：这份流水线在真实教学场景里能做什么、不能做什么，以及怎么用。

## 1. 它解决的教学问题

一份 7 题的手写作业，人工批改大约需要 10–15 分钟（要算、要核、要写批注）。这份流水线的定位不是"替学生做题交差"，而是**把"答案对不对"这一层先机械地核完**，让人只花时间在"过程好不好"上。

具体能自动完成的三件事：

1. **拆题**：把作业原件（Markdown / 纯文本）按题号切成独立题项。
2. **解 + 自校**：用 SymPy 精确求解，并把解代回原题验证（矩阵乘回单位阵、特征对满足 `Av=λv`、方程解回代残差为 0）。
3. **排版**：直接产出可提交的 PDF，中英文、上下标、矩阵、分式都能正常显示。

## 2. 怎么用在课堂上

| 场景 | 用法 | 注意 |
|---|---|---|
| 布置作业前 | 把题目喂给流水线，确认每道题都能被求解 | 解不出来的题会被标为 `unsolved`，正好暴露出"这题超出模板覆盖面"，可提前调整 |
| 批改客观题 | 用 `3_solutions.json` 里的 `answer_latex` 与 `verify_ok` 做对错预筛 | `verify_ok=false` 的题必须人工看，可能是题目本身有问题 |
| 出标准答案 | 一键生成 PDF 答案卷 | 概念题需老师自己写，系统会留白 |
| 扩展题型 | 在 `domain_skills/` 加 YAML + 在 `solve_kernel.py` 加一个求解器 | 一个求解器约 30–60 行，配套一个独立校验函数 |

## 3. 三个必须讲清楚的边界

1. **"能解"≠"全覆盖"**。6/7 是这份题目集上的结果，不是通用能力。当前覆盖：矩阵求逆、特征值/特征向量、线性方程组、可分离变量、一阶线性、二阶常系数齐次。**没覆盖**：非线性 ODE、级数解、偏微分方程、证明题。
2. **概念题不自动解**。第 7 题（为什么两个线性无关解构成通解）系统直接留白。让学生自己写，也避免系统生成一段看似正确、实则没有论证结构的文字。
3. **校验器会出错，且错的时候很自信**。开发中曾出现"正确解被判成错误"（`Derivative` 未求值导致残差非零）。因此任何 `verify_fail` 都必须人工复核，不能直接当判分依据。

## 4. 教学设计上的一个建议

把这份仓库当成"可拆解的教学样本"用，比当成"工具"用更有价值。它展示了三个可迁移的工程习惯：

- **退出码 0 ≠ 正确**：空白 PDF 那次，`rc=0`、文件 15,927 B，看起来完全正常。所以加了文本层自检门。（最终版答案卷为 6 页 / 4,163 字符 / 833,577 B。）
- **校验器必须独立于被测对象**：用同一套代码既算答案又判答案，等于自己给自己打分。
- **失败要留证据**：`unsolved` 和 `verify_fail` 都是显式字段，不会被静默吞掉。

这三条可以原样搬到任何"AI 产出需要被信任"的场景里。

## 5. 上手命令

```bash
pip install -r requirements.txt
python scripts/run_domain.py <作业原件.md> output --title "<标题>"
# 查看 output/3_solutions.json 的 meta 与每题 verify_ok
```

退出码 `7` 表示 PDF 内容自检未过（正文 < 200 字符或无中文），此时不要拿它当成品。
