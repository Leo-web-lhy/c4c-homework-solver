# 2023108610260_C4C 方案设计

## 1. 挑战目标与本次取舍

C4C 要求：给定一份**非微积分极限方向**的课后作业原件，构建一条流水线把它自动求解并排版成可交付的 PDF，同时把求解能力沉淀为可复用的 skill。

关键事实先行：starter 包内的 `test1_worksheet_cn.pdf` / `test2_worksheet_cn.pdf` 经 `pypdf` 抽取正文确认，分别是「切线与 ε‑δ 预备知识 Math 1A 工作单 3」和「函数的极限 Math 1A 工作单 4」，**两页内容全部属于极限与连续性方向**，按挑战「非微积分极限」的要求**不能用**。因此作业原件由我按线性代数与常微分方程方向自行命题（7 题：6 计算 + 1 概念），并在验证报告中如实标注为「自命题原件」，不冒充平台材料。

## 2. 总体架构

```
作业原件 .md
  → [stage1] ingested         原文 + 元数据（chars/lines/课程/姓名）
  → [stage2] parse_problems   题号切分 + 公式抽取 + 题型初判
  → [stage3] solve_kernel     SymPy 确定性求解 + 独立校验（oracle）
  → [stage4] render_html_pdf  LaTeX → MathML → 单文件 HTML
  → [stage5] PDF              Edge/Chrome headless --print-to-pdf
```

四段式职责分离，每一段都有落盘产物（`1_ingested.json` → `2_parsed.json` → `3_solutions.json` → `homework.html` → `homework.pdf`），任何一段失败都能单独定位与重跑。

## 3. 求解内核设计（本次的主要工作量）

`scripts/solve_kernel.py`（20.6 KB，纯 ASCII 源码，中文文案外置到 `domain_skills/la_ode_templates.json`）：

| 求解器 | 覆盖题型 | 独立校验方式 |
|---|---|---|
| `la_matrix_form` | 逆矩阵 / 行列式 | 代入 `A·A⁻¹ = I` 实算 |
| `la_eigen` | 特征值 + 特征向量 | 代入 `A·v = λ·v` 逐分量比对 |
| `la_solve_linear_system` | 线性方程组 | 解回代每一行，检查残差为 0 |
| `ode_separable` | 可分离变量 | 将 y(x) 代回原方程求残差 |
| `ode_linear_first` | 一阶线性 | 同上，残差须恒等于 0 |
| `ode_second_order_cc` | 二阶常系数 | 残差 + 特征根判别（相异/重根/复根） |

设计原则：**先确定性、后生成式**。SymPy 结果是权威来源，LLM 只在 `llm_backend.ask()` 可用时作为第二意见，`backend` 字段如实记录 `sympy` 还是 `llm`。

### 3.1 题目文本适配层

stage2 解析器只保证 `text` + `math_expressions`，不保证机器可算的结构。内核因此自带适配层 `enrich_problem()`，从自然语言文本反推可算输入：

- `_equations_from_text`：按 `;`/`；`/换行切分方程
- `_ode_from_text`：定位 `y'` / `y''` 头部，切出方程本体
- `_ic_from_text`：正则抽取 `y(x0)=y0`、`y'(x0)=dy0`

### 3.2 实际踩到的五个缺陷（均已修复，见验证报告）

1. `2x` 类隐式乘法 → SymPy `SympifyError`：加入 `_norm_math()` 归一化。
2. 方程前带叙述文字（`Solve the linear system ...`）→ 整句进 SymPy 报错：加入 `_strip_label()`，剥题号、剥冒号前叙述，同时保护 `det`/`rank` 等函数名。
3. 中文句号 `。` 留在方程尾部 → 解析失败：扩展 `rstrip` 字符集。
4. 残差 oracle 用 `subs()` 替换 `y(x)` 后导数项仍是 `Derivative` 未求值 → **正确解被判为「校验未通过」**（假阴性）：补 `.doit()` 后再 `simplify()`。
5. 校验计数用中文文案前两字做前缀匹配，而「校验通过」「校验未通过」共享同一前缀 → 计数恒为 ok：改为 `_verify_line()` 回写结构化 `verify_ok` 进 `meta`，计数只认布尔值。

第 4 条尤其值得记录：**一个假的校验器比没有校验器更危险**，因为它会让人误以为解错了，进而"修"掉正确答案。

## 4. 排版路线

本机无 `pdflatex / xelatex / lualatex / latexmk / tectonic / pandoc`（已逐项探测），因此不走 LaTeX 编译：

```
answer_latex → latex2mathml.converter → MathML
             → 内联 CSS 单文件 HTML（含 CJK 字体族）
             → msedge.exe --headless --print-to-pdf
```

- 依赖已装：`latex2mathml 3.81.1`、`pypdf 7.1.1`、`pdfplumber 0.11.10`。
- 降级留痕：MathML 转换失败的公式会被记录进 `MATH_FAIL` 并打印 `[math-fallback] n expression(s)`，不静默吞掉。
- 无浏览器时 `html_to_pdf()` 返回 False，驱动保留 `.html` 并以退出码 5 声明「未产出 PDF」。
