## 二、边界情况处理（`solverQuality` 子项）

| 脏输入 | 处理方式 | 位置 |
|---|---|---|
| 隐式乘法 `2x` | 归一化为 `2*x` | `scripts/solve_kernel.py` 归一化层 |
| 题面中文叙述混排 | 先剥叙述再抽表达式 | `scripts/parse_problems.py` |
| 中文句末标点 | 抽取前剥离 `。；，` | 同上 |
| 概念题（无法计算） | 不求、不编造，走人工通道并单列标注“非求解器输出” | `domain_skills/manual_answers.json` |
| 模板未覆盖题型 | `solved=false` + 答案卷留白说明 | `output/3_solutions.json` 对应题 `meta` |

## 四、未达标项（如实列出，不做“环境限制”式掩盖）

1. **无 LLM 对照基线**：本机 4 家厂商密钥均未配置（Moonshot 401 / DashScope 404），挑战建议的“与通用大模型对比”未做；替代为人工逐题手算复核。
2. **仅 Windows + Python 3.12.13 实跑**：未做 Linux/macOS 验证，未接 CI。
3. **样本规模小**：7 题、自命题，求解率 6/7 不能外推为通用能力。
4. **排版非原生 LaTeX**：走 HTML + MathML + 浏览器打印，公式排版规范度低于 LaTeX 原生方案。
